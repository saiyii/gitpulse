Privacy policy

Last updated: November 25, 2026

This policy covers the GitPulse instance run at gitpulse.saiyiidev.com: the GitPulse GitHub App and the GitPulse Discord bot. If you run your own copy of GitPulse, you are responsible for the data it handles.

Short version: GitPulse stores which repositories each Discord channel follows, and nothing else. No accounts, no tracking, no ads, nothing is sold.

What is stored

For each subscription created with /subscribe:

  • the Discord server ID and channel ID,
  • the repository name (for example saiyii/gitpulse),
  • the event types you chose (releases, push, issues, pulls),
  • the ID of the GitHub App installation covering that repository, if any,
  • the date the subscription was created.

That's the whole database. It does not contain Discord user IDs, messages, GitHub usernames or email addresses.

What is processed but not stored

  • GitHub webhooks. When something happens on a repository where the app is installed, GitHub sends an event (release, push, issue, pull request). GitPulse turns it into a Discord message for the subscribed channels and then discards it. Only the delivery ID is kept in memory for a short time, to avoid posting the same event twice.
  • Slash commands. Discord sends the command and who used it. GitPulse uses that to answer and to check permissions (for example the role needed by /issue create).
  • GitHub API responses for /repo and /release, used to build the reply.

Issues created from Discord

/issue create opens an issue on GitHub with the title and text you typed, followed by a line saying it was opened from Discord with your Discord username. That issue is public if the repository is public, and is then governed by GitHub's terms and privacy statement. You can edit or delete it on GitHub like any other issue.

Logs

The server keeps technical logs (events received, repository names, channel IDs, errors) to keep the service running and to debug problems. They are not shared with anyone and are only kept as long as they are useful for that.

Permissions

On GitHub, the app asks for read access to contents, metadata and pull requests, and read/write access to issues. It never touches code. On Discord, the bot asks to view channels, send messages and embed links, and uses no privileged intents: it cannot read message content or the member list.

Where the data lives

GitPulse runs on a server rented from OVHcloud. Traffic to gitpulse.saiyiidev.com may pass through Cloudflare. GitHub and Discord process data under their own policies.

Deleting your data

  • /unsubscribe deletes a subscription immediately.
  • Removing the bot from a Discord server deletes all of that server's subscriptions.
  • Deleting a channel deletes its subscriptions.
  • Uninstalling the GitHub App stops all events and removes the stored installation IDs.

You can also email support@saiyiidev.com to ask what is stored about your server, or to have it deleted.

Changes
