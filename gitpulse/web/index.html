Your GitHub releases, pushes and pull requests, posted to Discord.

GitPulse is a Discord bot paired with a GitHub App. Pick a repository and a channel, and it posts what happens there. You can also look up repos and open issues without leaving Discord.

Set up in three steps

  1. Install the GitHub App

    On your account or organization, for all repositories or only the ones you pick.

  2. Add the bot to your server

    It only needs to read channels, send messages and embed links.

  3. Subscribe a channel

    /subscribe owner/repo releases,push in the channel where updates should go.

What it posts

releasesNew releases with their notes and download links. On by default.
pushCommits pushed to the default branch, five at a time with a link to the full diff.
issuesIssues opened, closed and reopened.
pullsPull requests opened, merged, closed and reopened.

Commands

/repo owner/nameStars, forks, language, latest release and last push.
/release owner/nameThe latest release.
/subscribe, /unsubscribeChoose what the current channel receives. Needs Manage Server.
/subscriptionsEverything the server follows.
/issue createOpen an issue on GitHub. Limited to a role you choose.
